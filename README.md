# URL Shortener CLI

Консольный сервис сокращения ссылок.

Короткая ссылка выводится в формате `clck.ru/<code>`, но **это локальный сервис**: коды генерируются самим приложением, 
без обращения к внешнему API. Открытие выполняется командой `open`, которая запускает браузер через `Desktop.browse(...)`.

---

## Возможности

- **Создание коротких ссылок** из длинных URL (create).
- **Уникальные ссылки для каждого пользователя**: один и тот же URL у разных пользователей даёт разные коды.
- **Лимит переходов** (max clicks): после исчерпания ссылка становится недоступной.
- **Время жизни (TTL)**: по истечении срока ссылка автоматически удаляется.
- **Уведомления в консоль**: создание, приближение к лимиту, лимит исчерпан, TTL истёк, удаление.
- **Идентификация пользователя по UUID** без авторизации:
    - UUID создаётся при первом запуске и сохраняется локально;
    - можно передать UUID вручную или сбросить.
- **Управление ссылками владельцем**: список, удаление, изменение лимита.

## Требования

- Java **21** (в `pom.xml`)
  > Если в вашем окружении Java 17, можно понизить `maven.compiler.source/target` до 17 — код совместим.
- Maven 3.8+
- ОС с поддержкой открытия браузера через `Desktop` (на headless-системах будет выведен URL для ручного открытия).

## Быстрый старт

### 1) Создать ссылку

```bash
java -jar target/url-shortener-cli-*.jar create https://example.com --max 10
```

Пример вывода:

```
Generated and saved new UUID: <ваш-uuid>   # появится при первом запуске
Короткий код: 3DZHeG  (полный: clck.ru/3DZHeG)
```

> В дальнейших командах используйте **код** (`3DZHeG`), а не строку `clck.ru/3DZHeG`.

### 2) Открыть ссылку по коду (учтёт клик)

```bash
java -jar target/url-shortener-cli-*.jar open 3DZHeG
```

- Если лимит кликов исчерпан — команда вернёт ошибку и покажет уведомление.
- Если TTL истёк — ссылка будет удалена и тоже вернётся ошибка.

### 3) Посмотреть список своих ссылок

```bash
java -jar target/url-shortener-cli-*.jar list
```

Пример строки:

```
Link{3DZHeG -> https://example.com, ttl=86400s, clicks 2/10}
```

### 4) Изменить лимит кликов (только владелец)

```bash
java -jar target/url-shortener-cli-*.jar update 3DZHeG --max 50
```

### 5) Удалить ссылку (только владелец)

```bash
java -jar target/url-shortener-cli-*.jar delete 3DZHeG
```

## Пользователь и UUID

### Как UUID выбирается по умолчанию

- Если не передавать `--uuid`, приложение:
    1) попробует прочитать UUID из `{dataDir}/user.properties`;
    2) если файла нет — сгенерирует UUID и сохранит.

### Переопределение UUID

- Явно указать UUID (например, чтобы имитировать другого пользователя):
```bash
java -jar target/url-shortener-cli-*.jar --uuid 00000000-0000-0000-0000-000000000001 list
```

- Сгенерировать новый UUID и сохранить его локально:
```bash
java -jar target/url-shortener-cli-*.jar --reset-uuid list
```

## Уведомления

Сервис выводит уведомления в консоль (например):
- «приближение к лимиту» — когда остаётся ≤ 20% кликов,
- «лимит исчерпан» — при первой попытке исчерпания (не спамит повторно),
- «TTL истёк» — при истечении срока или при фоновой очистке,
- «удалено» — при удалении владельцем или очисткой.

## Хранилище данных

По умолчанию данные лежат в:

- **Linux/macOS:** `~/.urlshortener/`
- **Windows:** `%USERPROFILE%\.urlshortener\`

Файлы:

- `links.json` — все созданные ссылки (персистентность между запусками)
- `user.properties` — UUID пользователя (`user.uuid`)

### Как сменить папку данных

Можно переопределить системным свойством:

```bash
java -Durlshortener.dataDir=/tmp/urlshortener -jar target/url-shortener-cli-*.jar list
```

## Конфигурация приложения

Конфигурация читается из `src/main/resources/application.properties`.  
**Системные свойства имеют приоритет**, поэтому удобно переопределять параметры при запуске.

Ключи:

- `link.defaultTtlSeconds` — TTL по умолчанию (сек), сейчас: `86400` (24 часа)
- `link.defaultMaxClicks` — лимит кликов по умолчанию, сейчас: `100`
- `cleanup.intervalSeconds` — период фоновой очистки (сек), сейчас: `60`

Пример запуска с переопределением:

```bash
java \
  -Dlink.defaultTtlSeconds=3600 \
  -Dlink.defaultMaxClicks=20 \
  -Dcleanup.intervalSeconds=10 \
  -jar target/url-shortener-cli-*.jar create https://example.com
```

## Валидация URL

`create` принимает только валидные URL со схемой `http://` или `https://`:

✅ `https://ru.stackoverflow.com`  
❌ `ru.stackoverflow.com`
